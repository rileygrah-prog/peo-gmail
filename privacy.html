Privacy policy

Last updated 19 November 2026.

Who it's for

PEO is a private tool used by one person, its owner, on their own Google account. It isn't available to the public.

What it reads

With the owner's permission, PEO uses the Gmail API with read-only access (gmail.readonly). It reads the owner's own Gmail labels and message details (sender, subject, date, labels and Gmail's short preview). This lets it sort the owner's inbox into a report for the owner.

What it does with the data

The data is processed on the owner's own computers and kept there. It isn't sold or shared with anyone. It isn't used for advertising, and it isn't used to train AI models. PEO never sends, deletes or changes email.

PEO's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can remove PEO's access at any time in their Google Account, under Security → Third-party connections.

Contact

Use the support email shown on PEO's Google sign-in screen.
